# Blogger Posts — source and publishing guide

The files in this folder are intended as **post-body content** for Blogger.

## Publish or update a post

1. Open the Blogger dashboard for [AIOU Coaching](https://aioucoaching.blogspot.com/).
2. Go to **Posts** and create or edit the post.
3. Use the HTML editor to paste the contents of [post-template.html](post-template.html), then replace all instructional placeholders.
4. Set the actual post title, permalink, labels, search description, and images in Blogger.
5. Preview on mobile and desktop, publish, and open the live URL to check formatting and links.

Repository edits do not automatically publish to Blogger. Update the live post separately and verify the public result.

## Page vs post

| Blogger Page | Blogger Post |
| --- | --- |
| Long-lived information such as About, Privacy, Terms, and the tool directory | Dated guides, study tips, assignment guidance, and other search-focused articles |
| Usually not organized by post labels or archives | Can appear in archives, labels, feeds, and related-post areas |
| URL and title are managed in Blogger Pages | Title, permalink, date, and labels are managed in Blogger Posts |

Choose the content type that best fits its purpose; do not create duplicate pages simply to target similar keywords.

## Recommended article structure

1. Use one clear main topic. Blogger's post title often supplies the page's main heading, so avoid adding a duplicate `h1` in the body.
2. Start with a concise, direct answer in the `.key-takeaways` block if it helps readers.
3. Organize the explanation with descriptive `h2` and `h3` headings.
4. Cite official AIOU sources for university policies, admissions, dates, fees, and results.
5. Add screenshots or tables only when they add information; provide meaningful alt text for images.
6. Link to relevant tools or guides, such as the [AIOU Tool Kit](../pages/aiou-tool-kit.html), after confirming the live URL.
7. Add genuine FAQs only when they help readers. Structured data must match visible content and current search-engine policies.
8. Add an in-article ad slot only if the theme and ad configuration actually use it.
9. Set accurate labels and a unique search description in Blogger.
10. Check spelling, mobile layout, accessibility, and every internal/external link before publishing.

## Accuracy and trust

- Do not claim a guess paper is official, leaked, or guaranteed to match an exam.
- Do not invent deadlines, fees, eligibility requirements, citations, or author credentials.
- Mark dates as reviewed only after checking the content.
- Distinguish independent study support from official university services.
- Explain when an AI tool may send text to an external provider.
- Do not publish private student data or credentials.

## Template

Use [post-template.html](post-template.html) as a starter, not as finished copy. Replace every placeholder, validate the HTML and structured data, and remove any sections that do not apply.
