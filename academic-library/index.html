Academic tutor ka study method

  1. Apna current programme aur semester prospectus se confirm karein.
  2. Course code ko LMS/CMS course list aur assignment sheet se match karein.
  3. Official book download karke unit titles aur learning outcomes note karein.
  4. Har unit ko concept → example → practice → self-test ke sequence mein parhein.
  5. Assignment ka jawab apni understanding se likhein; book aur official sources ka reference dein.
  6. Exam se pehle definitions, formulas, diagrams aur past mistakes revise karein.
Source and accuracy note: Programme offerings and course codes change by semester. Always verify the active prospectus and course code for your own admission/semester. This library provides original explanations and navigation; it does not replace AIOU's official textbook or tutor instructions.
