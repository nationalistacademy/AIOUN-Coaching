📅 AIOU Workshop Planner

Workshop ka schedule paste karein (ya quick builder se banayen) — tool calendar reminders, Google Calendar links, WhatsApp message aur quiz ka reminder (2nd last class) bana deta hai.

1️⃣ Workshop schedule

Har line mein ek class: date (05/12/2026 ya 5-Dec-2026), time (10:00 AM - 12:00 PM), workshop ka naam, aur (optional) venue / link. Columns kisi bhi tarteeb mein ho sakte hain. Date ko DD/MM/YYYY samjha jata hai.
Student ID na chale to course code likhein, phir apna group chunein.

2️⃣ Reminders aur quiz

Google Calendar file ke andar likhe alarms aksar ignore kar deta hai. Yeh mode alag event bana deta hai, jis par Calendar ki apni notification aa jati hai.
ℹ️ Time hamesha Pakistan time (UTC+5) mein hai. Yeh tool AIOU ka portal khud fetch nahi karta (portal student ID / region / program se khulta hai) — aap portal se schedule copy karke paste karte hain. Schedule ki final tasdeeq hamesha AIOU portal / LMS se karein.
