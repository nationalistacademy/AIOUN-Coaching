📥 Bulk Assignment Downloader

Generate multiple MS Word files and download them all in one ZIP folder.

👨‍🎓 Students List

💡 How it works?

  • ✅ Step 1: Add student details (Name, Roll No, Course).
  • ✅ Step 2: Paste their assignment text.
  • ✅ Step 3: Click Generate.
  • ✅ Result: The tool will create separate MS Word files for each student and pack them into a single ZIP file for you.

Note: This tool runs 100% in your browser. Your data is never sent to any server. It is fast, free, and secure.
