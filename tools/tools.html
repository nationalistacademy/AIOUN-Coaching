Tool kaise istemal karein

  1. Tool chunein. Apni zarurat ka tool kholein.
  2. Details likhein. Questions ya student information enter karein.
  3. Preview/quiz run karein. Result check karein.
  4. Download ya save karein. Jahan supported ho PDF/image export karein.
