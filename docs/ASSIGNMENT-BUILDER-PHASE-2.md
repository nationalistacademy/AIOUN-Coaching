# Assignment Builder Phase 2 — Native DOCX, Urdu RTL and Media

**Status:** Feature branch for review; no live Blogger publishing.
**Repository:** `nationalistacademy/AIOUN-Coaching`
**Branch:** `feat/assignment-builder-docx-rtl-media`
**Parent branch:** `feat/assignment-builder-mvp`

## Implemented scope

### Native DOCX
- Replaces the HTML-disguised `.doc` export with a real Office Open XML `.docx` generated by the browser-side `docx` library (version 9.1.0).
- Includes student/course metadata, question headings, rich text, headings, lists, tables and references.
- Includes embedded PNG/JPEG/WebP images and generated flow-diagram images.
- DOCX is generated in the browser and downloaded locally; no assignment content is uploaded to an API.
- The library is loaded from jsDelivr. If the CDN is unavailable, the page displays an error and asks the user to reload/check connectivity.

### Urdu and mixed-language editing
- Adds explicit RTL and LTR toolbar actions for the selected paragraph/block.
- Retains `dir=rtl/ltr` through sanitization, local draft save, preview and DOCX conversion.
- Automatically aligns plain Urdu/Arabic-script paragraphs and question headings right.
- English paragraphs remain left-aligned; mixed content can be manually set with the toolbar.

### Images and diagrams
- Adds image insertion for PNG/JPEG/WebP files up to 350 KB each, maximum four per answer.
- Only base64 data images are retained in the editor; remote image URLs and invalid image elements are removed by the sanitizer.
- Adds a simple flow-diagram builder for 2–6 user-provided steps; it creates a PNG locally in the browser.
- Media remains in the browser's local draft storage. Users on shared devices should clear drafts after exporting.

## Automated coverage
- Browser test loads the pinned DOCX UMD bundle from the repository's generated `vendor/docx.min.js` test asset (prepared by `npm run build:vendor`).
- Tests cover RTL block direction, safe image insertion, DOCX download and the existing builder privacy/sanitizer flows.
- Run `npm test`; this runs `npm run build:vendor` and the Playwright suite.

## Limitations and user guidance
- The Word file is a native DOCX, but equation rendering in Word may differ from MathJax preview; LaTeX markers remain text/markup rather than guaranteed native Office equations.
- PDF export continues to use the existing page-preview rasterization path.
- The flow-diagram tool creates a simple vertical process diagram, not a full drag-and-drop diagram editor.
- Large images are rejected to protect local-storage quota and mobile performance.
- Browser local storage is device/browser-specific and is not a cloud backup.
- This is an independent educational preparation tool, not an official AIOU system. Students remain responsible for writing, reviewing and submitting their own assessed work.

## Out of scope
No Blogger page/theme publishing, hosting deployment, DNS, Firebase/Supabase, LMS, authentication, enrollment, quiz, student records or production configuration changes.
