# Student Tools

This folder contains independent browser-based study and productivity tools for learners. Open a tool directly in a modern browser; unless a tool explicitly documents otherwise, do not assume it requires an account or a server.

## Student privacy
- Use fictional data when demonstrating a tool.
- Check whether a tool saves data in browser storage; clear shared-device data after use.
- Export files only to a device/account controlled by the student.
- Do not enter passwords, CNIC details or unnecessary personal identifiers.
- Do not upload copyrighted course books or paid materials unless the user has permission.

## Tool acceptance checklist
- [ ] Mobile and desktop layouts are usable.
- [ ] All visible buttons and links work.
- [ ] Required fields, invalid values and empty states are handled.
- [ ] Keyboard navigation, labels and focus states are present.
- [ ] Urdu and English text render correctly where supported.
- [ ] Print/PDF/CSV/DOCX output is checked where offered.
- [ ] Browser console has no relevant errors.
- [ ] Storage and network behavior are documented.
- [ ] Tests cover the main success path and at least one failure path.

Report defects with the tool filename, browser/device, exact steps, expected result and actual result. Do not include real student information in screenshots or issues.
