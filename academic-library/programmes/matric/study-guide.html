Is guide ko kaise use karein?

  1. Pehle apna group confirm karein: General ya Science.
  2. Apne admission record se har enrolled course code note karein.
  3. Matric Course Code Library mein code select karein aur official book link open karein.
  4. Har unit ko pehle samjhein, phir apne alfaaz mein short notes banayein.
  5. Assignment questions ko book ke relevant units se map karein; jawab khud samajh kar likhein.

Matric mein parhai ka practical tareeqa

English aur Urdu

Roz thora reading practice karein. Mushkil words ki vocabulary list banayein. Grammar rule ke baad apne 3–5 example sentences likhein.

Mathematics

Formula ratta lagane ke bajaye us ka matlab samjhein. Solved example dekhein, phir book band karke milta-julta sawal khud solve karein.

Science

Har concept ko daily-life example se connect karein. Diagram ko label karna aur process ko apne alfaaz mein explain karna practice karein.

Islamiyat / Pakistan Studies

Headings, key terms, dates aur cause/effect points ki short notes banayein. Sirf paragraphs yaad karne ke bajaye topic ka central idea samjhein.

Weekly self-study routine

  • 5 din: Roz 60–90 minutes; aik main subject aur 15 minutes revision.
  • 1 din: Pichlay haftay ke topics ka self-test aur weak areas ki list.
  • 1 din: Rest ya pending reading; aglay haftay ka realistic plan.

Apne available time ke mutabiq routine chhota ya bara kar sakte hain. Consistency, aik din mein bohat zyada parhne se behtar hoti hai.

Assignments aur exams ki tayari

  1. Question ko do martaba parhein aur command word samjhein: define, explain, compare ya calculate.
  2. Relevant book unit aur headings identify karein.
  3. Answer ka short outline banayein: introduction, main points, example aur conclusion.
  4. Jawab apni language mein likhein; book se exact paragraphs copy na karein.
  5. Maths/science mein steps, units, diagrams aur final answer dobara check karein.
  6. Submission se pehle current AIOU instructions, deadline aur formatting CMS/official portal se verify karein.
Academic honesty: Yeh resource learning support ke liye hai. Assessed assignment student ka apna kaam hona chahiye. Hum concepts, outlines, examples aur draft feedback samajhne mein madad dete hain; ready-made submission ko apna kaam keh kar jama karwana theek nahi.
