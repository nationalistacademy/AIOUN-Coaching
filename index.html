⚙️ Worker kaise setup karein

AI wale tools worker/ folder ka Cloudflare Worker use karte hain. Wrangler se:

cd worker
npx wrangler secret put DEEPSEEK_API_KEY
npx wrangler secret put AUTH_TOKEN      # ek ya kai tokens, comma se alag
npx wrangler deploy
Deploy ke baad Worker URL aur token studio ke "Multi-ID Response" section me save karein — chahein to kai IDs (apni + backup) rakh lein.
